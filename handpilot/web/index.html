    Every frame is 21 hand landmarks with confidences. Send them to your own code. The mouse doesn’t have to be involved.

    from handpilot import HandStream

with HandStream() as hands:
    for f in hands:
        print(f.landmark("index_tip"))

    That Python snippet, or python run.py --stream, talks to the phone directly, and the phone serves one program at a time. While this window is open, use UDP or the browser stream instead. Formats are in docs/data.md.
